# Security

Please don't report security problems in public issues.

Use GitHub's private reporting instead: on the repository's **Security** tab, choose **Report a vulnerability**. You'll get a reply within a week, and a fix will be released as soon as it's ready, with credit to you unless you'd rather not be named.

Things worth reporting include a way for Claude's code tools to read files outside `video-demo.ai.code.paths` or matching `video-demo.ai.code.deny`, a way to reach the studio or the recorder's sign-in link where the studio is disabled, and a way to read private videos or requests without access.
