# Code of conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful and welcoming, assume good intent, and keep criticism about the work, not the person. Harassment, insults, and personal or political attacks are not accepted in issues, pull requests, discussions or anywhere else the project is represented.

## Reporting

If someone's behaviour makes you uncomfortable, report it privately to the maintainer, [@ogunsakin01](https://github.com/ogunsakin01), through GitHub's private reporting on the repository's **Security** tab, or by direct message on GitHub. Reports are kept confidential.

The maintainer may remove comments, commits, code and issues that break this code of conduct, and may block people who repeatedly or seriously break it.
